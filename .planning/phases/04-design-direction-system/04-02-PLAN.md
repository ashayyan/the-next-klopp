Existing: `makeView(input)`, `canonicalToScreen(view, p)`, `View.pxPerMetre`, `Orientation` (src/pitch/view.ts); `discDiameter(pxPerMetre)`, `unitsPerPx`, `GLYPH_TEXT_PX = 12` (glyphSize.ts); `createSampler(scene)` (src/scene/playback/sample.ts); `parseScene` (src/scene/validate.ts); `BadgeShape` radius 8 screen px, `Chip` (MarkGlyphs.tsx).

New, `src/pitch/glyphs/placement.ts` (pure, no React):
- `interface Box { x: number; y: number; w: number; h: number }` in screen pixels; `boxesIntersect(a, b): boolean`.
- `placeBadge({ start, end, discs, view }): ScenePoint` returns the canonical position of the badge centre; candidates in order: left of travel, right of travel, behind the start, ahead of the start, each at `discDiameter/2 + 8 px` (converted to metres with `view.pxPerMetre`) from `start`; the first candidate whose 16 px badge box clears every disc box and lies inside the viewBox wins; if none clears, the left-of-travel candidate is returned. Direction is `end - start`; a zero-length event uses "up the screen".
- `placeChip({ anchor, width, height, view }): { x: number; y: number }` returns the chip centre in screen pixels after the orientation transform; it prefers the side the current code draws, moves to the opposite side of the anchor when the box would cross an edge, then clamps inside the box.
</interfaces>
