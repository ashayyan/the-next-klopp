New, `scripts/design/copy-fonts.ts` (CLI, `node scripts/design/copy-fonts.ts [--check] [--prune]`):
- Collects every `files[].src` from the inputs of `listTokenInputs(root)` (exported by `scripts/design/build-tokens.ts`: the system input, Markdown through `extractTokensBlock`, plus every direction set that exists).
- Maps `/fonts/<family>/<file>` to `node_modules/@fontsource-variable/<family>/files/<file>`; copies bytes to `public/fonts/<family>/<file>`.
- Writes `public/fonts/LICENSES.md` from each package's `package.json` (version), `metadata.json` (`license.attribution` or the equivalent copyright field) and `LICENSE` (full text), families in alphabetical order, `\n` line endings.
- `--check`: no writes; exit 1 listing each missing, differing, unreferenced or stale item. `--prune`: deletes font files and empty family folders under `public/fonts/` that no token input references.
</interfaces>
