New, `scripts/review/lib.ts` (pure, Vitest-tested):
- `parseArgs(argv): ReviewArgs | { error: string }` with route, `widths` (default [375, 768, 1440]), `theme` (`light|dark|both`, default `both`), `port`, `states` (comma-separated query strings). Unknown flag gives the error copy "Unknown option {flag}. Use --widths, --theme, --port or --states.".
- `slugRoute(route)`: lower-case, every run of characters outside `[a-z0-9]` becomes `-`, trimmed; refuses routes not starting with `/`, containing `..`, whitespace, `\`, or `://`.
- `CHECKS`: registry `{ id, severity: "fail" | "warn", source: "dom" | "static" | "taste" }[]` holding all 22 ids of the 04-UI-SPEC "Checks" table (ids implemented later report status `skipped` until their plan lands).
- `buildReport(input): ReviewReport` (schemaVersion 1, the 04-UI-SPEC `report.json` shape; `tasteSkill` is `null` until 04-06), `renderReportMd(report)` (first line `REVIEW: PASS — {f} fail, {w} warn` or `REVIEW: FAIL — …`, then a check by width table, offenders by check, screenshot paths), `exitCodeFor(report)` (0 pass with warnings allowed, 1 any fail).

New, `scripts/review/browser.ts`: `ensureServer({ route, port }): Promise<{ baseUrl, stop(): Promise<void> }>`, `capture(...)` returning per width, theme and state the screenshot path, SHA-256 and the plain data collected by page-side functions (boxes, computed styles, text); thresholds are applied in Node by `lib.ts`.
