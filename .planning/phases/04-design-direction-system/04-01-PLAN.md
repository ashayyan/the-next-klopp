<objective>

Purpose: one generator, two output shapes (system and scoped), proven end to end through Tailwind into the app and the pitch before any screen is built.

New, `scripts/design/tokens.ts` (pure, erasable TypeScript, no `node:fs` import at module level so browser code and Playwright specs can import it):
- `extractTokensBlock(markdown: string): string` returns the body of the single fenced block whose info string is `tokens`; 0 or 2+ blocks throw `"DESIGN.md must hold exactly one tokens block, found N"`.
- `parseTokens(json: unknown, source: string): TokenDocument` validates with `tokenDocumentSchema`, checks the required keys in both themes, resolves `{group.key}` aliases inside the same theme (cycle and unknown alias throw with the key path), and returns resolved values.
- `generateSystemCss(doc, source): string` and `generateScopedCss(doc, scope, source): string` return byte-stable CSS (fixed key order from the schema key lists, `\n` line endings, trailing newline, first line a comment naming the source and "generated by scripts/design/build-tokens.ts, do not edit").
- `SYSTEM_INPUT = "src/routes/dev-directions/tokens/floodlit.tokens.json"`, `SYSTEM_OUT = "src/styles/tokens.css"`, `DIRECTION_DIR = "src/routes/dev-directions/tokens"`; `scopeFor(id) = [data-direction="<id>"]` and `isValidScope(s)` checks `^\[data-direction="[a-z-]+"\]$`.

CSS names (04-UI-SPEC "Parsing and generation rules", refined by 04-RESEARCH Pattern 1): `color.*` and `pitch.*` to `--<key>`; `data.*` to `--data-<key>`; `font.<k>` to `--font-<k>` plus `--font-<k>-stretch` when `$extensions.tnk.stretch` is set; `text.<k>` to `--text-<k>`, `--text-<k>--line-height`, `--text-<k>--font-weight`; `space` to `--space-<k>`; `radius` to `--radius-<k>`; `shadow` to `--shadow-<k>` (empty array is `none`); `border` to `--border-<k>`; `duration` to `--duration-<k>`; `easing` to `--ease-<k>` as `cubic-bezier(a, b, c, d)`; `icon.stroke` to `--icon-stroke` and `--icon-linecap`; `pitch.glyphText` to `--pitch-glyph-text`.
