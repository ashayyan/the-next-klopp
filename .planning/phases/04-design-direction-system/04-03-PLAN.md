**As a** learner, **I want to** pick a visual direction from real rendered screens and get a design system that enforces it, **so that** every lesson looks designed, accessible and consistent instead of generic.

<objective>
Build the colour-blind safety gate DSGN-02 requires: one colour maths module (`scripts/design/lib/color.ts`, also used later by the review CLI's contrast checks) and `scripts/design/check-palette.ts`, which validates every categorical, sequential and diverging scale and the team, ball, zone and UI contrast pairs in both themes of every token set, and fails CI on a regression.

Implements CONTEXT "Colour-blind safety": CVD simulation for deuteranopia, protanopia and tritanopia with a minimum ΔE, WCAG contrast 4.5:1 for text and 3:1 for UI, "using the dataviz skill's validator approach" (formulas re-implemented from 04-RESEARCH "Palette maths"; the skill is a host tool outside the repo, so none of its code is copied), CI gate. Team distinction never relies on colour alone: shapes stay from Phase 3, this gate is the colour half.

Purpose: the pick (04-10) disqualifies any direction that fails gate G1, and DESIGN.md section 3.1 embeds this script's table.
Output: colour library with tests, the gate CLI with golden and negative tests, npm scripts.
</objective>
