## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer or agent to local git | hooks are the first gate before history; they can be skipped with --no-verify |
| test code to secret scanners | test fixtures must exercise secret rules without themselves looking like leaks |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-14 | Tampering | .husky hooks bypass via --no-verify or HUSKY=0 | medium | transfer | CI guards job (Plan 09) re-runs the guard on every PR; ADR 0007 records the hook as a fallback, not protection |
| T-01-15 | Tampering | scripts/verify/hook.ts probe leaving a bad file staged or committed | medium | mitigate | requires an empty index before starting, never calls git commit, removes the probe in finally, verify step asserts a clean index and no raw/ folder |

| T-01-17 | Information disclosure | secret-shaped test data | medium | mitigate | fake secrets assembled at runtime from fragments; guard `--tracked` re-run proves the test files stay clean |
