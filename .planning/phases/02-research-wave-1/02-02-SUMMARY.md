# Phase 2 Plan 02: Open-data coverage matrix Summary

**A `klopp-pipeline coverage` Typer command that reads seven providers' public indexes through an allow-listed, size-capped, cached fetcher and commits a 110-row matrix showing the Premier League has 418 StatsBomb and 380 Wyscout event matches, 13 Liverpool tracking goals and no other tracking or 360 data.**

## Accomplishments

- Single command `npm run data:coverage` (= `uv run --project pipeline klopp-pipeline coverage`, options `--out --refresh --offline --deep --providers`) writes `research/pl-data-sources/coverage-matrix.json` and `.md`.
- Live run of 2026-11-27T21:04:43Z reached every provider; no row is unreachable. Numbers match the research golden values exactly:

| Provider | Data type | PL matches | Total matches |
|----------|-----------|-----------|---------------|
| StatsBomb | event | 418 (2015/16: 380, 2003/04: 38, Arsenal only) | 3,961 over 80 competition-seasons |
| StatsBomb | 360 | 0 | 426 available overall, none in the PL |
| Wyscout | event | 380 (English first division, wyId 364, 2017/18) | 1,941 over 7 competitions |
| SkillCorner | broadcast-tracking | 0 | 20 (19 closed, 1 not_started; README says 10) |

| Metrica | event and tracking | 0 | 3 anonymised games |
| Last Row | tracking | 13 | 19 Liverpool goals (manual count) |
| PFF FC | broadcast-tracking | 0 (request-only) | 64 documented |

- Wyscout identity check: the first match in the England file is "Burnley - AFC Bournemouth", which supports the assumption (A8 in the research) that wyId 364 is the Premier League.
- `--deep` was also run live (to a temp folder, not committed): the Last Row CSV recount gave 19 distinct plays and 13 Premier League plays, confirming the manual constants.

**1. [Rule 3 - Blocking] Biome would reformat recorded fixtures**

**2. [Rule 2 - Missing critical] Figshare redirect host allow-listed**
- **Found during:** Task 2 (fixture recording)
- **Issue:** `ndownloader.figshare.com/files/14464622` returns a 302 to `44c1cec316ec56bca76dfd65d2882b20.r2.cloudflarestorage.com` (Cloudflare R2 bucket figshare-com-storage); without it the Wyscout row would always be unreachable. The plan anticipated this.
- **Fix:** Added that exact host to `ALLOWED_HOSTS` with a comment; the redirect handler still refuses every other host.
- **Files modified:** pipeline/src/klopp_pipeline/net.py
- **Commit:** 8717f27

**3. [Rule 1 - Correctness] Premier League 360 rows shown in Markdown**
- **Found during:** Task 3
- **Issue:** The "PL-relevant rows first" detail tables hid the PL 360 rows (0 matches), so the reader could not see the evidence for "no PL 360 data".
- **Fix:** Rows whose competition is "Premier League" or "English first division" are always shown.
- **Files modified:** pipeline/src/klopp_pipeline/coverage.py
- **Commit:** 8f05c63
