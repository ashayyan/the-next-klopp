`lib/layout.ts`: `layoutConcepts(concepts)` builds a dagre graph (`rankdir: "LR"`, `ranker: "network-simplex"`, fixed `nodesep`, `ranksep`, fixed node width and height), one node per concept, one edge per prerequisite pair, returns `{ width, height, nodes: [{ id, x, y, w, h }], edges: [{ from, to, points }] }` with coordinates rounded to one decimal so output is deterministic.

`lib/summary-html.ts`: `buildSummaryHtml(bundle, layout, decision)` returns the whole document as a string: inline `<style>`, an inline SVG of the graph (each node a `<g class="node" data-id="<id>" tabindex="0" role="button" aria-label="<title>, Part <P>">` with the Part letter printed inside), the bundle subset the page needs embedded as `<script type="application/json" id="data">` with every `<` replaced by `\u003c`, and one inline script that wires selection (click, Enter, Space) and sets `document.documentElement.dataset.ready = "1"` at the end of init. Compute the SHA-256 of the exact inline script text at build time and emit `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; style-src 'unsafe-inline'; img-src data:; script-src 'sha256-<base64>'">`. The script builds every dynamic node with `document.createElement` and `textContent` (never by assigning markup strings), and only creates links whose URL starts with `http://` or `https://`, with `rel="noopener noreferrer"`.

`build-summary.ts`: CLI `node scripts/research/build-summary.ts [--root research] [--adr docs/decisions/0008-watch-gym-l1-clip-supply.md] [--out research/summary/index.html] [--check]`; `--check` rebuilds in memory and exits 1 when the file differs or is missing; exits 1 with a clear message when `--root` has no concept-map.json. Write with `\n` endings.

`check-summary-browser.ts`: `node scripts/research/check-summary-browser.ts <html> [--screenshot <png>]` finds Edge, else Chrome, runs it with an argument array (`--headless`, `--disable-gpu`, `--dump-dom`, the `pathToFileURL` of the page), and exits 0 only if the dumped DOM contains `data-ready="1"`; with `--screenshot` it also runs `--screenshot=<png> --window-size=1440,900`. Exit 2 with a message when neither browser exists. If the hashed CSP blocks the script under file:// (assumption A5 fails), switch to `script-src 'unsafe-inline'` while keeping `default-src 'none'`, and record the change in the SUMMARY.

`summary.test.ts`: build the fixture page (root `scripts/research/fixtures/mini`) in memory and assert: no `<script src`, `<link`, `@import`, `url(http`, `fetch(`, `XMLHttpRequest`, `WebSocket` or `EventSource`; a CSP meta containing `default-src 'none'`; the CSP hash equals the SHA-256 of the inline script; one `g.node` per concept; no raw `</script` inside the embedded JSON; two builds are byte-equal.
