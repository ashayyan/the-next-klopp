From 03-02: `createSampler`, `sceneDuration(scene)`, `keyframeTimes(scene)`, `MotionMode`. From 03-04: `SceneLayer({ scene, t, mode })`, `DEV_SCENES`, `findDevScene`.

New (src/scene/playback/store.ts, uses `createStore` from `zustand/vanilla` and `useStore` from `zustand`):
- `interface PlaybackState { t: number; duration: number; keyframes: number[]; playing: boolean; ended: boolean; speed: 0.25 | 0.5 | 1; motion: MotionMode; holdMs: number; play(): void; pause(): void; toggle(): void; replay(): void; seek(t: number): void; stepNext(): void; stepPrev(): void; jumpBy(seconds: number): void; first(): void; last(): void; setSpeed(s): void; setMotion(m): void; tick(dtMs: number): void; load(scene): void }`
- `createPlaybackStore(scene, { motion })` (a factory, never a module singleton, so node tests drive it); `load` resets to paused at t 0.
- `tick` smooth: t += dt × speed, clamp at duration, then playing false and ended true. `tick` stepped: accumulate `holdMs`; once it reaches 500 / speed ms, jump t to the next keyframe; at the last keyframe stop as above. `play` while ended behaves as `replay` (t 0, then play). `seek`, `stepNext`, `stepPrev`, `first`, `last` pause.
- `defaultMotion(prefersReducedMotion: boolean): MotionMode` (stepped when true).
- loop.ts: `startPlaybackLoop(store): () => void` (one rAF loop, dt from rAF timestamps, capped at 100 ms per frame; stop when unsubscribed); `frameStats` = rolling window of per-frame work ms (rAF callback start to the next commit mark) and rAF intervals; `markCommitted()` called from a `useLayoutEffect` in the playback layer; `window.__pitchFrameStats` set only when `import.meta.env.DEV`.
</interfaces>
