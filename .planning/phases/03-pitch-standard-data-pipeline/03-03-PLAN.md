**As a** learner, **I want to** have one canonical pitch and a reproducible open-data pipeline that feed the same Scene/Frame format, **so that** every board, quiz and replay I see is geometrically correct and traceable to data.

<objective>
Build the provider coordinate converters (PITCH-02) by porting kloppy 3.19.1's zone-warp algorithm to `src/pitch/coords.ts`, with expected values generated by kloppy itself into a committed fixture that both Vitest and pytest check (the cross-language parity test).

Purpose: CONTEXT "Canonical coordinate system": landmark-preserving piecewise-linear mapping for fixed-landmark providers, translation/flip for same-size tracking, specs pinned at kloppy 3.19.1, one TS module as the single place coordinate bugs can live (costly decision). Opta and Wyscout fixed landmarks are documented as "as implemented by kloppy 3.19.1" (CONTEXT post-research decision).
Output: kloppy pinned in the pipeline, `landmarks` generator and CLI, socket-blocking conftest, `coords.ts` with tests, committed fixture.
</objective>
