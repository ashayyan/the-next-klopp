| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-13 | Tampering | kloppy loaders | medium | mitigate | kloppy receives `BytesIO` or local paths from `fetch_source` only; socket-blocked tests (03-03 conftest) fail any hidden network call |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | No new packages in this plan (kloppy pinned in 03-03) |
