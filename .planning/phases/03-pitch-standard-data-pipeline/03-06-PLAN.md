From 03-05: `load_allow_list()`, `get_source()`, `fetch_source(source_id, *, raw_root, offline)`, `RECIPES` (each with `name`, `source_id`, `dataset`, `build(raw_root, offline) -> Scene`), `dump_scene(scene) -> bytes`.

New:
- manifest.py: `NAME_RE = ^[a-z0-9][a-z0-9.-]*$` for dataset and version names; `version_id(files: dict[str, bytes]) -> str` = "v1-" + first 12 hex of sha256 over the sorted lines "{path}:{sha256}\n"; `write_version(dataset, files, meta, *, data_root) -> Path` (resolve the target and assert it stays under `data_root`; if the directory exists, compare every data file's sha256 with the existing manifest: equal → no-op returning the path, different → raise `ImmutableVersionError`; never overwrite); pydantic `Manifest` with the fields in the truths, `extra="forbid"`; scene files named `scene-<scene id>.json`; per-file cap 1 MB when shippable.
- publish.py: `publish(*, data_root, public_root, allow) -> Path` copies each shippable version directory byte-for-byte (same immutability rule under `public_root`), then writes `public_root/catalog.json` = `{ "schemaVersion": 1, "datasets": [ { "dataset", "version", "license", "licenceUrl", "attribution", "manifest": "<dataset>/<version>/manifest.json", "files": [ { "path", "sha256", "bytes" } ], "scenes": [ { "id", "label", "path" } ] } ] }` sorted by dataset then version, written only when its content changes. `catalog.json` is the only mutable file under `public/data/`.
- cli.py: `recipe <name>` now writes through `write_version` (keep `--out` as an optional preview path); `publish`; `run-all` = fetch every source that has files → every registered recipe whose source is cached → publish; options `--offline`, `--sources`, `--raw-dir`, `--data-dir` (default `data`), `--public-dir` (default `public/data`), all resolved from `REPO_ROOT`.
</interfaces>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-14 | Tampering | `manifest.py` path building | medium | mitigate | `NAME_RE` on dataset, version and scene ids; resolved target asserted under `data_root` / `public_root` before any write |
| T-03-15 | Tampering | committed artifact mutation | high | mitigate | `write_version` refuses different bytes in an existing version; hash-derived version ids; Vitest recomputes sha256 and version ids; Biome excluded so formatters cannot rewrite them (git-level M/D/R gate follows in 03-08) |
| T-03-16 | Information disclosure (licence) | `publish.py` | high | mitigate | copies a version only when both its manifest and the allow-list say `shippable: true`; 1 MB per-file cap; local-only datasets never reach `public/data` (03-08 adds the dist gate and git guard) |
| T-03-SC | Tampering | npm/pip/cargo installs | high | accept | No new packages in this plan |
</threat_model>
