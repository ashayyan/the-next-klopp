src/pitch/view.ts
- `type Orientation = "horizontal" | "vertical"`; `type Matrix = readonly [number, number, number, number, number, number]` (SVG a b c d e f order)
- `interface ViewInput { length: number; width: number; runoff: number; orientation: Orientation; cssWidth: number }`
- `interface View extends ViewInput { viewBox: string; vbWidth: number; vbHeight: number; cssHeight: number; pxPerMetre: number; groupTransform: string | undefined; cssMatrix: Matrix }`
- `makeView(input: ViewInput): View`. Horizontal: viewBox `-r -r L+2r W+2r`, no group transform, s = cssWidth/(L+2r), cssMatrix `[s,0,0,s,s*r,s*r]`. Vertical: viewBox `-r -r W+2r L+2r`, groupTransform `matrix(0 -1 1 0 0 L)`, s = cssWidth/(W+2r), cssMatrix `[0,-s,s,0,s*r,s*(L+r)]`. pxPerMetre = s.
- `applyMatrix(m, p)`, `invertMatrix(m)` (own 6-number helpers; node has no DOMMatrix), `canonicalToScreen(view, p)`, `screenToCanonical(view, cssX, cssY)` (CSS px relative to the container top-left), `canvasMatrix(view, dpr)` (cssMatrix scaled by dpr), `sizeInMetres(minPx, metres, maxPx, pxPerMetre)` (clamp the screen size, return metres), `autoOrientation(stageCssWidth)` (vertical below 480 px).

src/pitch/geometry.ts
- `LAW1` = { goalWidth 7.32, goalAreaDepth 5.5, goalAreaWidth 18.32, penaltyAreaDepth 16.5, penaltyAreaWidth 40.32, penaltyMarkDistance 11, centreCircleRadius 9.15, penaltyArcRadius 9.15, cornerArcRadius 1, goalDrawDepth 2 } with a comment citing `src-ifab-laws-2026-27#law1-*` locators; goalDrawDepth is a drawing convention, not a Law value (say so in the comment).
- `pitchGeometry(length, width): PitchGeometry` returning metres: field rect, halfway line, centre circle, centre mark, goalAreas [left, right], penaltyAreas [left, right], penaltyMarks [left, right], penaltyArcs [left, right] as `{ cx, cy, r, from, to, mid, d }` (d is the SVG path, sweep flag 1, arc only outside the penalty area), cornerArcs (4 paths, r 1, inside the field), goals [left, right] drawn outside the goal line 2 m deep.

src/pitch/Pitch.tsx
- `interface PitchProps { length?: number /*105*/; width?: number /*68*/; orientation?: Orientation; runoff?: number /*3*/; title: string; desc?: string; interactive?: boolean; canvas?: ReactNode; onPointerCanonical?: (p: { x: number; y: number } | null) => void; initialCssWidth?: number /*960, used until ResizeObserver measures*/; children?: ReactNode }`
- `usePitch(): { view: View; length: number; width: number; orientation: Orientation; runoff: number; upright: (x: number, y: number) => string | undefined }` (`upright` returns `rotate(90 x y)` in vertical so glyph text reads upright, undefined in horizontal).
- DOM: one `position: relative` container with `aspect-ratio` from the viewBox; bottom `<svg aria-hidden="true">` (run-off rect `var(--pitch-runoff)`, field rect `var(--pitch-surface)`); the `canvas` slot; top `<svg>` (transparent) with `role="img"` (or `role="group"` when `interactive`), `<title>` "Pitch, {length} by {width} metres — {title}", optional `<desc>`, then `<g data-canonical-root transform={groupTransform}>` holding `<g data-layer="markings">` and then `children`. Only the top SVG receives pointer events.
